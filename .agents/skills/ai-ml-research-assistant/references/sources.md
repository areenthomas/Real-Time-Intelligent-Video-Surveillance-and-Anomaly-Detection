# Trusted discovery sources

## Papers

- arXiv: https://arxiv.org/ (preprints; inspect version history)
- Semantic Scholar: https://www.semanticscholar.org/
- OpenAlex: https://openalex.org/
- Crossref: https://search.crossref.org/ (DOI metadata)
- Hugging Face Papers: https://huggingface.co/papers
- CVF proceedings: https://openaccess.thecvf.com/
- ACL Anthology: https://aclanthology.org/
- NeurIPS proceedings: https://proceedings.neurips.cc/
- PMLR: https://proceedings.mlr.press/

Use search synonyms, backward/forward citations, and author/publisher pages. Deduplicate DOI, arXiv and published versions. Prefer reading the primary paper PDF instead of a snippet.

## Datasets

- Hugging Face Datasets: https://huggingface.co/datasets
- Kaggle: https://www.kaggle.com/datasets
- UCI Repository: https://archive.ics.uci.edu/
- OpenML: https://www.openml.org/
- Google Dataset Search: https://datasetsearch.research.google.com/
- Original creators' pages and official benchmark sites.

Verify license, terms, provenance, access, labels, partitions, privacy and current availability at original source.

## Models and code

- Hugging Face Models: https://huggingface.co/models
- GitHub: https://github.com/
- Official challenge leaderboards and source repositories.

Check code/weights license, identity of author repository, release status, dependencies, evaluation scripts and reproduction instructions. An unofficial implementation must be labelled as such.

## Source reliability order

Primary paper/proceedings → author dataset/model card → benchmark organizer → independent reproducibility study → secondary review/blog. Show credible disagreements, not false consensus.
